### 简介📖

这是一个 Yunzai-Bot 插件包，提供群内各种小游戏以及相关管理工具，为 **akasha-terminal-plugin** 的完全本地化改版「虚境·月」。

以修仙世界观统合全部玩法：修炼突破、娶群友、装备丹药、宗门战争、伪玩家江湖、世界Boss、遗蜕秘境、灵兽养成与各类法宝，配合**全游戏统一的绝对战力体系**与 LIFO 交互锁，指令流畅不冲突。

### 安装说明🖥️

**方式一：git clone（推荐，支持 `#虚境更新`）**

```bash
git clone https://gitee.com/frost-moon05/xujing-yue-plugin.git plugins/xujing-yue-plugin
```

GitHub 备用：`git clone https://github.com/frostmoon0/xujing-yue-plugin.git plugins/xujing-yue-plugin`

安装后，Bot 主人发送 `#虚境更新` 即可拉取最新代码（更新完成后请重启 Bot 生效）。

**方式二：手动放置**

- 将本插件目录放入 BOT 根目录的 `plugins` 文件夹下，重启 Bot 即可（依赖 Yunzai-Bot v3）
- 配置变更后使用 `#虚境重置配置` 进行配置更新操作（**注意**：该指令会覆盖本地修改，使用后请重新按需求设置）
- 可选：安装 [Guoba-Plugin（锅巴）](https://gitee.com/guoba-yunzai/guoba-plugin) 后，可在 Web 面板中可视化修改本插件配置

### 配置说明⚙️

- 配置文件位于 `config/` 目录，主配置为 `config/xujing.config.yaml`（由 `#虚境重置配置` 从默认配置生成）
- 常用配置项（节选，详细说明见 YAML 内注释）：

| 配置段   | 说明   |
|---|---|
| `duel_cfg`   | 决斗/修炼/突破冷却时间、战斗力依赖系数   |
| `wife_cfg`   | 娶群友各项概率与冷却、彩球开奖、秘境播报、挂机收益   |
| `trial_cfg`   | 幻境试炼每日次数、回合数、排行播报   |
| `limit_cfg`   | 全局指令频率限制（防刷屏）   |
| `reply_cfg`   | 长消息渲染图片的阈值与分页   |
| `realm_cfg`   | 遗蜕秘境总开关/群白名单/场次周期/搜刮上限   |
| `idle_cfg`   | 闲置灵石清理（默认超5天未使用虚境指令清空灵石）   |

### 存档位置💾

- 存档独立存放于 Yunzai 本体 `data` 目录：`data/xujing-yue-plugin/save/`
- 内含 `qylp`（娶群友）/ `battle.json`（决斗境界）/ `bag`（背包丹药）等，独立于插件目录，替换/更新插件不影响存档

### 常见问题❓

<details><summary>展开</summary>

- **存档路径在哪？**
  存档存放在 Yunzai 本体 data 目录：`data/xujing-yue-plugin/save/` 下，独立于插件目录，替换/更新插件不影响存档。

- **报错 `xxx is not defined`**
  使用 `#虚境重置配置` 后重启 Bot。

- **怎么改配置？**
  在 `config/` 文件夹里修改 `xujing.config.yaml`；也可用锅巴面板可视化调整。

- **娶群友相关功能报错 `cannot read ... (reading 'sex' 或 'nickname')`**
  有人老婆或本人退群导致，使用 `#虚境清除无效存档` 即可。

</details>

### 开发相关🛠️

- **单元测试**：`node --test`（`test/` 目录），改动代码后请保持全量测试通过
- **全游戏统一战力**：所有战斗玩法复用 `components/fight.js` 的绝对战力体系，禁止按玩法另设独立战力或互相矛盾的换算；胜率上限允许 **100%**
- **交互锁**：LIFO 栈路由数字指令，动作必须走合法状态机，杜绝绕锁/吞指令

### 改版说明📝（相对上游的改动）

本插件是 [akasha-terminal-plugin](https://gitee.com/go-farther-and-farther/akasha-terminal-plugin)（@越追远）的改版，核心改动如下：

**本地化**
- 更名为 `xujing-yue-plugin`（虚境·月），指令统一为 `#虚境xxx` 系
- 界面/配色/文案全面修仙化（玄夜霓虹风），世界观完全本地化
- 存档独立存放于 `data/xujing-yue-plugin/save/`，与原版互不干扰

**玩法扩充**
- 新增灵兽·宠物系统：600+ 图鉴、7档血脉品质、捕抓/孵化/成长/出战/交易
- 新增宗门系统：创建/职位/宝库/设施/战争/俘虏/矿山/外交/天牢
- 新增遗蜕秘境/幻境试炼：破界/探索/遭遇/组队/夺宝/出口围剿
- 新增世界Boss与登仙令、妖丹掉落；藏宝阁洗劫、伏击/仆从玩法
- 新增傀儡法宝（打造/升级/祭出/分解）、万魂幡/万魂窟/养魂阵
- 新增简月王朝（城池/阵法/屠城）、神游蛊·定仙游、世界分区（大区/小区/跨区/税率/宗门占领）

**架构与稳定性**
- 全游戏统一**绝对战力**体系：所有战斗玩法复用同一套战力，胜率上限允许 100%
- 交互锁升级为 LIFO 栈：逛街/渡劫/换装/赠送/出售/跨区等数字指令统一路由，杜绝冲突吞指令
- 统一 `YuePlugin` 指令代理：权限/冷却/状态锁/异常兜底
- 装备/物品原子化落盘，含存档备份、清理、迁移与损坏恢复
- 新增 `node --test` 单元测试体系

**安全与公平**
- 修复锁定状态下用裸数字绕锁的漏洞，动作必须走合法状态机
- 闲置灵石清理、拉黑名单、权能管理、防重复/防超发校验
